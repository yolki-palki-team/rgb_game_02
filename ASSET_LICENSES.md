# Asset provenance

All PNG sprites, tiles, icons, UI ornamentation and WAV sound effects under `game/assets/` are original procedural works created for RuneForge by `scripts/generate_assets.py` and `scripts/generate_blacksmith.py`. They are provided under CC0-1.0 (public domain dedication): https://creativecommons.org/publicdomain/zero/1.0/ . No commercial game assets are used.

Godot's bundled default font is used at runtime under the engine's third-party font licenses (Noto Sans, SIL Open Font License). The engine itself is MIT licensed: https://godotengine.org/license/ . No external fonts are redistributed by this project.

Downloaded development tools and official RGB reference source are ignored under `tools/`, not game assets. RGB library license: MIT, https://github.com/RGB-Tools/rgb-lib/blob/1eaf0024c591e41843eb80cc8834082292668871/LICENSE .

The blacksmith and anvil are original CC0 pixel art generated by `scripts/generate_blacksmith.py`. QVAC SDK 0.21.1 is Apache-2.0; Qwen3 4B is Apache-2.0 (https://huggingface.co/Qwen/Qwen3-4B). The SDK downloads its pinned Q4_K_M model descriptor into the ignored local cache; model weights are not redistributed in this repository.
